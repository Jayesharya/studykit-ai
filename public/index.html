      PRIVACY / AI NOTES

      Your notes are yours.

      StudyKit does not save notes or generated kits to a database. When you choose “Build my study kit,” the note text is sent to the Gemini API through this app’s server so it can generate your study materials.

      Your API key stays on the server and is never sent to the browser. Add it to a local .env file for development, or configure it as a secret where you host the app.

      Generated explanations and answers can be wrong. Treat the kit as a study aid and verify important details with your course materials.
